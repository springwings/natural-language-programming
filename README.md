## 这本书讲什么

编程正在发生一场根本性的变化。过去，你得先学几年编程语言，才能把一个想法做成软件。今天，你可以用**自然语言**——也就是你平时说话、写字的语言——告诉 AI 你想要什么，让它帮你把软件做出来。

这不是一本「提示词大全」，也不是一本教你现在就去背语法的书。这本书要教你的是一套**方法**：

- 像**产品经理**一样定义软件——把模糊的想法说清楚
- 像**工程师**一样拆解问题——把大目标拆成一个个能执行的小任务
- 像**用户**一样测试产品——找出问题、描述问题
- 像**项目负责人**一样指挥 AI——让 AI 改对地方、别越改越乱

读完这本书，你不一定会写传统代码，但你一定会拥有一种新的能力：**把一个想法，变成一个别人能用的软件。**

## 适合谁读

- 完全没有编程基础，但一直有个软件想法的人
- 用过 AI 聊天，但不知道怎么让它真正「做出东西」的人
- 让 AI 做了个东西，却不知道怎么改、怎么改对的人
- 想给自己的工作、生活做一个小工具的非技术人员
- 想理解 AI 时代「编程」到底意味着什么的人

## 怎么读这本书

1. **第一篇**先建立认知，不急着动手。
2. **第二到第六篇**是方法主线，建议按顺序读，边读边练。
3. **第七篇**五个实战项目，最好自己跟着做一遍，哪怕只做完第一个。
4. **第八篇**是给你「升级」用的，等你做完项目再回来看。

每一章都有：**场景引入 → 概念讲解 → 真实对话示例 → 插图 → 常见坑 → 小结与练习 → 可复制的指令模板**。

## 本书特色

- **以对话为主线**：大量真实的「人怎么说 / AI 怎么答 / 人怎么纠正」示例，而不只是抽象道理。
- **重视「改」而不是只重视「做」**：初学者的真正痛点，是软件做出来后不知道怎么改。
- **五个完整实战**：任务管理、记账、AI 文档助手、客户管理、自己的 AI 应用，全部走完整流程。
- **中英双语**：每种语言都是完整独立的一版，方便不同读者阅读与协作翻译。
